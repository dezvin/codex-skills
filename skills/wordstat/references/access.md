# Установка и доступ

Переноси весь каталог `wordstat` вместе с `SKILL.md`, `agents/`, `references/` и плоским `scripts/` в каталог навыков Codex. Внешний Python-пакет, исходники проекта и сторонние библиотеки не требуются. Нужен Python 3.11+. Каталог навыка не является папкой данных пользователя.

```text
python "<SKILL_DIR>/scripts/run.py" doctor
```

`doctor` проверяет местные настройки без внешних запросов и без вывода ключей/ID. Наличие credentials не является обещанием живого доступа: при отказе API прочитай безопасный код ошибки, не покупай повторные запросы вслепую.

## Окружение

| Переменная | Назначение |
|---|---|
| `WORDSTAT_API_KEY` **или** `WORDSTAT_IAM_TOKEN` | Один способ авторизации; не задавай оба. |
| `WORDSTAT_FOLDER_ID` | Каталог Yandex Cloud. Не переносится в отчёт или исходник. |
| `WORDSTAT_TARIFF_RUB_PER_1000` | Проверенная цена GetTop за 1000 запросов в рублях. |
| `WORDSTAT_TARIFF_CHECKED_ON` | Дата проверки цены, `YYYY-MM-DD`. |
| `WORDSTAT_CAPACITY_HOURLY` | Разрешённая текущая квота; при отсутствии используется стандартный fallback 100, при подтверждённом увеличении задаётся новое значение. |
| `WORDSTAT_CAPACITY_RPS` | Предел в секунду; по умолчанию 10. |
| `WORDSTAT_CAPACITY_BUCKET` | Общая локальная группа учёта запросов; по умолчанию `wordstat_primary`. Это не утверждение о фактической области enforcement Яндекса. |
| `TOPVISOR_USER_ID`, `TOPVISOR_API_KEY` | Нужны только для отдельного добора частотностей. |
| `TOPVISOR_PROXY_MODE` | `system` по умолчанию; `direct` — явный прямой сетевой маршрут при диагностированной проблеме прокси/VPN. |

На Windows запуск подхватывает отсутствующие значения из пользовательских переменных среды. Уже заданные значения процесса имеют приоритет. При изменении квоты в старом процессе обнови только численную настройку или используй новый процесс; не выводи весь environment.

Ключ создаётся в Yandex Cloud/AI Studio для service account с ролью `search-api.webSearch.user` и scope `yc.search-api.execute`; платёжный аккаунт должен быть активен. Если доступа нет, потребуется действие в кабинете владельца. Не создавай и не меняй credentials самостоятельно. Для установки другим пользователем настрой его собственное окружение; личные credentials автора в пакет не входят.

Проверенный тариф — внешний изменяемый факт, не встроенная вечная цена. При отсутствии настройки прочитай актуальную [официальную тарификацию](https://aistudio.yandex.ru/ru/docs/search-api/pricing), запиши только численные настройки и дату. Изменение capacity не увеличивает бюджет сохранённого сбора.

Локальный учёт не видит запросы других инструментов к тому же аккаунту. При throttling сохраняй работу и диагностируй доступность; 429 не является показателем оставшегося баланса квоты.
