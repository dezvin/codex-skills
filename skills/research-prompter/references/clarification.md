# Clarification

Use this reference to resolve a material gap in intent, help the user form a direction, or settle a consequential conflict. It is not an interview script.

## Decide Whether An Answer Is Needed

An intent question is justified when all these conditions hold:

1. No answer is already available or reliably recoverable.
2. Different plausible answers would materially change the research task, a binding boundary, applicability of evidence, or useful result.
3. The value belongs to the user's intent, preference, circumstances, or constraints rather than to what the research should discover.
4. The question helps the user answer or meaningfully choose a direction.

Test materiality concretely: what reasonable assignments would result from different answers, and what consequential difference would that create? Do not calculate an ambiguity score or demand a numerical threshold.

A missing critical file or authorized excerpt is an input dependency. A minimal request for an identifier after an unresolved framing gap is also legitimate: ask which entity the user means, not for its future research findings. Use the entrypoint's orientation lookup boundary; external search cannot choose intent for the user.

## Route The Gap

| Situation | Action |
| --- | --- |
| Available context already gives the value | Use it. Resolve competing versions by applicable authority and freshness rather than asking for the entire context again. |
| A low-risk detail follows reliably from the request | Recover it without a question; retain a consequential assumption as an assumption. |
| A material user choice remains unclear | Ask a concrete question. |
| Object identity or terminology is critically ambiguous | Use the orientation lookup gate; if unresolved, request the minimal distinguishing information. |
| An external fact, alternative set, or field structure is unknown but the task is defined | Make it part of the research, not a briefing question or preliminary investigation. |
| The user deliberately leaves direction open | Preserve exploration and the researcher's ability to discover useful structure. |
| The value changes only optional presentation polish | Choose a reasonable form or omit it; do not block delivery. |
| Binding requirements are incompatible | Identify the exact conflict. If authority cannot settle it, ask which condition may change. |

Do not infer a market from the conversation language, business criteria from a topic name, or a preferred strategy from an industry default. Subject knowledge is not owner preference.

## Conduct The Dialogue

Ask about an actual decision. Offer brief examples or choices when they help, while allowing the user's own answer. Do not present invented options as an exhaustive set.

Independent material questions may be grouped. When an answer determines the next question, proceed sequentially. The number of questions and rounds follows the unresolved branches, not scenario labels or fixed quotas.

When intent is emerging, help the user identify a desired contribution: understand a field, test a hypothesis, inform a decision, or map approaches. Do not require them to know the new field's segments, methods, vocabulary, or research questions before exploration can begin.

Do not ask whether the user wants honest sources, uncertainty handling, or objectivity. Those are properties of the assignment, not mandatory policy choices.

Use a question tool if available and useful; ordinary conversation is sufficient otherwise. No particular tool, form, or interface is required.

Examples:

- A Russian-language request for market research does not establish Russia as the market. If location changes the user's intended business decision and is unavailable, ask about that decision.
- "I want to understand agent evaluation methods; I do not know the criteria yet" can support an exploratory assignment without a questionnaire.
- When the project already requires local processing of internal documents, preserve that constraint; do not ask the user to brief it again.

## Resume Or Localize The Limit

After an answer, update the existing frame and continue. Do not repeat resolved questions. Leave remaining matters of the research subject to the recipient.

If the user cannot answer, do not restate the same question as a mandatory barrier. Determine whether openness, investigation of options, or a narrow explicit assumption can preserve intent without making a material choice for the user.

A request for no questions allows legitimate openness and low-risk assumptions. It does not supply a missing permission, essential material, or arbitrary consequential choice. If a ready assignment is impossible, state the exact limitation; do not label an unfinished template as finished.

Waiting is not an answer. Silence neither confirms a proposed boundary nor authorizes an action.
